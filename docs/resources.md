# 地形库、模型与工程文件

## 可编辑工程

`scene.json` 使用 `version: 1`，保存世界名称、场地尺寸、物理步长、对象列表、六维位姿和各类型参数。长度单位为米，角度为弧度，坐标轴为 X 向右、Y 向上、Z 向上。俯视画布只是坐标投影，不改变 Gazebo 世界坐标。

救援预设保持原布局。基础组件默认静态，箱体和圆柱可调整静态开关、质量与摩擦；斜坡/台阶保持静态。修改高度后，请同时检查 Z：箱体、圆柱、减速带的位姿在几何中心；斜坡和台阶以底面为 Z=0。平地默认顶面为 Z=0。斜坡沿局部 +X 升高，台阶的 `height` 是每级高度，`length` 是总长度。

场地尺寸设置会同步基础地面尺寸；不会自动缩放围栏、安全区或其他对象。修改救援场地大小时，应自行调整这些对象布局。

保存导入模型的工程时，资源复制到 `<文件名>_assets/`，工程使用相对路径。移动工程时同时移动该目录。导出后，使用导出目录的 `scene.json` 可以再次编辑和导出，无需原始模型目录。

## 本地模型导入

选择含 `model.sdf` 或 `model.config` 的模型目录。`model.config` 可以指定其他 SDF 文件名。模型按整体导入，编辑器中的紫色矩形表示近似占位，不代替三维真实尺寸。

资源应放在同一目录树中，使用相对 URI 或 `model://本目录名/...`。导入前会检查 SDF 资源、OBJ/MTL 和 COLLADA 的材质/纹理引用。首版拒绝绝对资源路径、网络 URI、目录外依赖、符号链接和嵌套 SDF include；请先将资源整理成自包含模型。外部模型插件仍需要在运行主机安装，本工具不复制系统插件。

Fortress 的 DART/ODE 碰撞链路需要可用的网格法线。导入碰撞 OBJ 时，应提供三角面和法线；本项目生成的四面体和斜坡均包含显式法线。未经原生加载验证的外部模型，基础资源检查无法证明其物理兼容性。

同名来源模型使用对象目录隔离，避免资源覆盖。导出按实际资源需求配置搜索路径。

## 地形库

编辑器左下方选择一个目录后刷新，发现其直接子项：

| 类型 | 操作 |
| --- | --- |
| 本项目 `.json` | 双击打开为可编辑工程，提示处理未保存修改 |
| 模型目录 | 双击导入当前场景 |
| 完整 `.sdf` / `.world` | 双击按原文件启动独立预览，保留当前编辑内容 |

仓库的 `terrain_library/` 提供可编辑预设。外部完整 SDF 不反向解析成组件，也不自动合并机器人或自动下载 Fuel 资源。预览前应提供其完整本地资源；可以设置 `IGN_GAZEBO_RESOURCE_PATH`。
