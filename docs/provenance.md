# 素材来源与模型近似

## 原智能救援平台

仓库所有内置救援模型提取自用户授权的 `smart-rescue-sim/gazebo/generate_world.py` 输出。提取时生成脚本 SHA-256：

```text
a0c13458c44866003f2351fd433a96be084be90e6397a570f942bc99784d6986
```

该哈希与原平台最终验收记录一致。提取的基线包含 38 个模型、8 个目标、一台小车及其 6 个传感器和 4 个控制/反馈插件。四面体网格来自原平台程序化资产。发布授权涵盖这些生成代码与近似模型，采用 Apache-2.0。

场地为 3 × 3 m，原始轮距 0.13 m、轮半径 0.038 m、夹爪 P 增益 20。默认物理步长保留生成器的 0.001 s；原任务启动脚本曾选用其他实验参数，这些不作为本工具默认值。

## 近似边界

- 小车是代码构建的外观与碰撞近似，非 SolidWorks 原装配导出；底盘与传动采用简化差速模型。
- 物资尺寸来自原仿真；安全区细节、质量、摩擦和部分场地尺寸为仿真假设，不代表官方实物测量。
- 原安全区入口薄坡面仅视觉，无碰撞；首版保留该行为。新的实体斜坡组件为独立生成的闭合三棱柱。
- 静态障碍及目标与小车使用实体接触；无固定吸附、物块瞬移或策略真值兜底。
- 场景合法和传感器可用不代表某个控制策略的成功率。
